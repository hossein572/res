# چاشنی

وب‌سایت رستوران چاشنی؛ سفارش آنلاین، رزرو میز و پنل مدیریت. رابط کاملاً فارسی و راست‌به‌چپ است.

شعار: طعم خوب، حال خوب.

## اجرا

```bash
npm install
npm run dev
```

ساخت نسخه تولید:

```bash
npm run build
```

خروجی `dist` برای GitHub Pages همین مخزن آماده است و مسیر پایه `/4/` دارد. اگر مخزن دیگری است:

```bash
VITE_BASE=/نام-مخزن/ npm run build
```

برای انتشار در ریشه دامنه: `VITE_BASE=/ npm run build`.

## مسیرها

- `/` خانه
- `/menu` منو، با جستجو و فیلتر و مرتب‌سازی
- `/food/:id` جزئیات غذا، اندازه، افزودنی و قیمت زنده
- `/cart` سبد خرید
- `/checkout` ثبت سفارش
- `/order/:id` رسید
- `/track` پیگیری
- `/reserve` رزرو میز
- `/favorites` علاقه‌مندی‌ها
- `/account` حساب کاربری
- `/about` و `/contact`
- `/admin` پنل مدیریت

سبد، علاقه‌مندی‌ها، سفارش‌ها و تغییرات منو در `localStorage` می‌مانند.

## ورود آزمایشی

مشتری: در صفحه ورود، «ورود آزمایشی با حساب سارا محمدی» یا کد `۱۴۲۸`.

مدیر: مسیر `/admin` و رمز `چاشنی`.

کدهای تخفیف: `چاشنی۱۰`، `مهمون`، `طعم‌خوب`.
